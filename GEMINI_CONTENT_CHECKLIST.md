## How To Share The Gemini API Key Safely

- Do not paste the key into chat.
- Set it in your local shell session before running the script:
  - `export GEMINI_API_KEY='your_key_here'`
- If you want the value to persist, add it to your shell profile or a local `.env` file that is not committed.
- If using `.env`, keep it out of source control and verify it is ignored by `.gitignore`.
- I can read the environment key from the shell when the script runs, so the safest flow is to set it locally and then tell me to proceed.
